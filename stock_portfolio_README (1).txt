STOCK PORTFOLIO TRACKER

Description:
A Python program that calculates stock investment values using predefined stock prices and quantities entered by the user.

Features:
- Displays available stocks and their prices.
- Accepts stock symbols and quantities.
- Calculates individual stock investments.
- Displays a portfolio summary.
- Calculates the total investment.
- Saves portfolio details to a CSV file.

Concepts Used:
- Dictionaries
- Lists
- For loops
- If-else statements
- Input and output
- Arithmetic operations
- CSV file handling

Programming Language: Python

How to Run:
python stock_portfolio.py

Output File:
portfolio.csv

Note:
The stock prices are sample values and are not live market prices.

Purpose:
To practise Python data structures, calculations, and file handling through a simple portfolio management program.
